# Strident Barefoot — Full-Featured Footwear E-Commerce App

A high-performance, dark-luxury e-commerce web application for **Strident Barefoot**, managed and operated by **Ridgewell Supply Co LLC** (https://ridgewellsupplycollc.com/).

![Strident Barefoot](/public/hero_banner.jpg)

## 🏃 About The Brand
Strident Barefoot produces minimalist running shoes engineered to honor natural human biomechanics. Featuring a wide anatomic toe box, zero-drop platform, ultra-flexible 4mm TrailGrip sole, and proprioceptive ground-feel sensory feedback.

- **Product**: Strident TrailGrip Minimalist Running Shoe ($119.00)
- **Managed By**: Ridgewell Supply Co LLC

## ✨ Features

- **Header & Announcement Bar**: Interactive marquee bar ("Free Shipping on Orders Over $75 | 30-Day Guarantee"), sticky navigation header with cart badge, and mobile drawer menu.
- **Product Gallery**: 3 colorways (Stealth Black, Earth Olive, Summit Gray) with thumbnail strip switcher, animated transitions, and image zoom lightbox.
- **Interactive Sizing**: Men's & Women's US 7 to 13 size selector with interactive Size Guide modal (conversion table for US Men/Women, EU, UK, CM and measuring guide).
- **Cart Drawer**: Slide-in cart with quantity controls, promo code engine (`BAREFOOT10`, `STRIDENT15`, `TRAIL20`), and real-time total updates with free shipping progress bar.
- **Interactive Product Exploder**: Anatomical hotspot visualizer displaying TrailGrip technical features.
- **Comparison Table**: Responsive feature comparison table highlighting barefoot advantages versus traditional shoes.
- **Customer Reviews Carousel**: Responsive horizontal review carousel with star ratings and verified buyer badges.
- **Checkout & Payment Simulation**: 3-step checkout with credit card validation, auto-card type detection (Visa, Mastercard, Amex), and animated payment processing screen (*"Securing payment with Ridgewell Supply Co LLC gateway..."*).
- **Order Confirmation Page**: Detailed order summary with order number (`#STR-40912`), item summary, size confirmation, shipping address details, and 4-step delivery tracking timeline.
- **Legal Modals**: Privacy Policy, Terms of Service, Return & Exchange Policy, and Compliance & Legal Notice.

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS v4 + Custom Glassmorphic CSS
- **State Management**: Zustand
- **Animations**: Framer Motion
- **Form Handling & Validation**: React Hook Form + Zod
- **Icons**: Lucide React

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/coderarifbd/Strident-barefoot.git
cd Strident-barefoot

# Install dependencies
npm install

# Run dev server
npm run dev
```

Open [http://localhost:5174](http://localhost:5174) in your browser.
